# RepoInsight

RepoInsight is an AI-assisted software repository analysis platform built with C# and .NET.

The goal is to analyze source code repositories, reconstruct their architecture,
generate diagrams, detect engineering issues, and provide actionable technical diagnostics.

## Planned stack

- C#
- .NET
- ASP.NET Core
- Azure
- PostgreSQL
- React
- Azure AI

## Planned features

- Repository ingestion
- Source code scanning
- Technology detection
- Architecture reconstruction
- Dependency graph generation
- Automatic architecture diagrams
- Engineering diagnostics
- AI-assisted technical reports

## Status

Early development.
